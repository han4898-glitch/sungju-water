# 가뭄 대비 농업용 저수지 방류(공급)량 최적화 웹앱 — 성주댐 외 경북 저수지

경북대학교 토목공학전공 · 과제 「바이브 코딩을 활용한 수리·수문 모델 기반 웹앱 개발 및 배포」

한국농어촌공사 저수지 3,402개소 중 아무 저수지나 이름으로 찾아, **기상청 관측·예보 → 유입량(GR4J) → 논 필요수량 → 저수지 운영(pywr)** 을 모의하고,
**가뭄을 확률로 예측(ESP)** 해 **방류(공급)량 운영규칙을 최적화**하는 Streamlit 웹앱과 MCP 서버입니다. 기본 예시는 경북 성주댐(성주저수지)입니다.

- 웹앱: (배포 후 URL 기입)
- 실행: `streamlit run app.py` · MCP: `python mcp_server.py`

## 무엇을 하나

| 기능 | 내용 |
|---|---|
| 저수지 검색·현황 | 제원표 3,402개소 이름·지역 검색, RAWRIS 실시간 저수율·평년 대비·**농업가뭄 단계(정상~심각)**, 일별 저수율(2015~), 위치 지도 |
| 지형 | 국토지리정보원 DEM으로 유역·만수면 추출, 브이월드 위성영상 3D |
| 모의 | GR4J 유출 + FAO-56 증발산·논 담수심 물수지 필요수량 + pywr 저수지 네트워크(선형계획) |
| 운영규칙 | 관행 / 단계별 제한급수 / 예보 연계 / **공사 가뭄단계 연동(평년 대비 70·60·50·40%)** / 사용자 정의 |
| 최적화 | 저수율 경계 3개·구간별 공급비율·예보 절감률을 차분진화로 탐색, 목적: 부족 심도지수(SI) 최소 |
| 가뭄 예측 | 기상청 단기예보 + **1973년~ 과거 기상 앙상블(ESP)** + 관측 오차 보정 → 저수율 확률 전망, 기상청 장기전망 가중 |
| 가뭄 대응 검증 | SPI-3·6 기상가뭄지수, 실제 가뭄 해(2017·2022·2025) 재현, 규칙 과적합 확인(학습/검증 해 분리) |
| 한 번에 | **"가뭄 예측해서 공급량 설정"** → 권장 규칙, 오늘 공급 비율, 다음 관개기 월별 공급계획(천㎥) |
| MCP(가점) | Claude 데스크톱에서 "성주댐 가뭄 예측해서 공급량 설정해줘", "지금 가뭄단계 뭐야?" 등 15개 도구 |

## 모델 구조

```
기상청 ASOS(1973~) ─► ET0 (FAO-56 Penman-Monteith, 결측일 Hargreaves)
      │                    │
      ├─► GR4J 유역 유출 ─► 유입량 ──────────────┐
      │                                            ▼
      └─► 논 담수심 물수지 ─► 필요수량 × 공급계수 ─► pywr 저수지 ─► 관개 / 하천유지 / 수면증발 / 월류
                                         ▲
     운영규칙: 저수율(또는 평년 대비) 구간별 공급비율 × 예보 연계 절감
```

- 필요수량 = 써레질 용수(5/1~20, 140mm) + 담수 유지기(5/21~9/10) [Kc×ET0 + 침투 4mm − 유효우량(물꼬 80mm 초과분 배수)] ÷ 송수효율 0.8
- 공급계수·운영상한은 농어촌공사 일별 저수율로 보정 (`data/calibrated_params.json`, `config/sungju.toml`)
- pywr 결과는 독립 구현한 일 물수지 엔진(`engine/reference_engine.py`)과 교차검증 (차이 0)

## 검증 결과 (실측)

| 항목 | 결과 |
|---|---|
| 저수율 보정/검증 NSE | 성주 0.73 / 0.65, 영덕 묘곡 0.80 / 0.78 |
| ESP 10~90% 범위 적중률 (2019~2025 역검증) | 성주 50% → 71%, 묘곡 57% → 86% (관측 오차 보정 후) |
| 묘곡 2025 가뭄 재현 (그해 제외 학습) | 최악 10일 부족률: 관행 88% → 공사 가뭄단계 45% → 최적 규칙 23% |
| 공사 가뭄단계 규칙의 최저 저수율 (묘곡 2025) | 16.4% = 실제 관측 최저 16.4% |
| 자동 테스트 | 69개 + 웹앱 화면 7개 통과 (`pytest`) |

```
data/                  저수지 제원표, 기상청 관측(1973~), 일별 저수율, DEM(35801), 좌표, 보조 스크립트

```

## 실행

```bash
conda create -n sungju python=3.11 -y && conda activate sungju
pip install -r requirements.txt
streamlit run app.py
```

인증키(선택 — 없으면 저장된 자료로 동작, 실시간 갱신만 꺼짐): `.streamlit/secrets.toml.example`을 `secrets.toml`로 복사해 입력.
`VWORLD_KEY`(브이월드), `KMA_APIHUB_KEY`(기상청 API허브), `DATA_GO_KR_KEY`(공공데이터포털: 기상청 단기예보·농어촌공사 저수지 수위).

### MCP (Claude 데스크톱)
`claude_desktop_config.json`의 `mcpServers`에 추가:
```json
"krc-reservoir-water": {
  "command": "<conda env>\\python.exe",
  "args": ["<경로>\\mcp_server.py"],
  "env": { "PYTHONIOENCODING": "utf-8", "PYTHONUTF8": "1" }
}
```

## 한계
- 실제 방류·공급 기록이 없어 필요수량 추정치에 실측 저수율로 보정한 공급계수를 곱해 사용
- 성주 모형은 운영상한(76.8%)이 있어 실제 80~90% 고저수율을 표현하지 못함 → ESP에서 관측 오차 보정으로 보완
- 필요수량 매개변수(써레질·침투·Kc·송수효율)는 저수지별 조사값이 아닌 일반값, 공사 가뭄단계 절감률은 예시값
- 앙상블은 1973년 이후 기상만 포함하므로 그보다 극심한 가뭄은 확률에 나타나지 않음
